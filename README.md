# Bilibili 免登入顯示留言 (Bilibili Login-Free Comment Display)

![License](https://img.shields.io/github/license/pthuang01/bilibili-login-free-comments)
![Version](https://img.shields.io/badge/version-1.0.0-blue)

在未登入 Bilibili（B站）的狀態下，自動為你加載並顯示完整的留言區內容，提供幾乎與登入後無異的原生瀏覽體驗。

## ✨ 核心特色 (Features)

*   **無縫免登入**：突破 B 站限制，未登入狀態下也能暢讀評論區。
*   **全站支援**：完整適配影片 (Video)、番劇 (Bangumi)、動態 (Dynamic)、專欄 (Opus/Read)、漫畫 (Manga) 等多種頁面。
*   **還原原生 UI**：
    *   精確還原「大航海」裝扮卡片 (Sailing Cards) 及其漸層與自訂字首 (NO., CD., CO. 等)。
    *   修復子回覆區塊的縮排與垂直切齊問題。
    *   支援顯示版主與用戶專屬徽章。

*English Description:*

Automatically load and display Bilibili comment areas without logging in. Supports videos, dynamic posts, articles, and retains native UI formatting such as sailing cards, badges, and proper nested thread indentation.
